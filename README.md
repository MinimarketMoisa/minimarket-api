# Minimarket Backend API

API REST construida con **FastAPI**, **SQLAlchemy** y **PostgreSQL** para la gestión de productos, inventario, sucursales y pedidos.

## Requisitos previos

- Python 3.10+
- PostgreSQL 16+ instalado y corriendo localmente
